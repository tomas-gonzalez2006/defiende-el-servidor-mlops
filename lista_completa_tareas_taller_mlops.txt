- No incluir label, attack_cat ni id como entradas del modelo.
- No ajustar transformaciones con datos de validación o test.
- No repartir entradas predictoras idénticas entre entrenamiento y validación.
- No utilizar el test para elegir modelo ni umbral.
- La comparación de v1 y v2 se realiza con validación.

- El ZIP por sí solo no demuestra el historial de Git.
- Ejecutar dvc add no basta: los datos deben poder recuperarse desde el almacenamiento entregado.
- Subir modelos a Hugging Face no basta: hay que probar su recuperación por SHA.
- No se exige una accuracy mínima ni mejorar todas las métricas.
- No se exige video, aplicación web, API, Space, servicio de pago ni servidor encendido.
- Se permite usar asistentes de IA, pero se debe declarar cómo se utilizaron y qué se verificó.
